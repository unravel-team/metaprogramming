# TypeScript Scaffold library

Install this package with your package manager:

```sh
corepack pnpm add <your-package-name>
```

Use its dependency-free library API:

```ts
import { example } from "<your-package-name>";

example(21); // 42
```

This package contains only compiled library JavaScript, declarations, and source
maps. It does not include application runtime dependencies or application
commands.
